# i3

*Starter notes from the project's known design. Check them against the
source before acting on them.*

## What it is

- **Language:** C. **License:** BSD 3-Clause.
- **Base:** X11 (XCB).
- **Scope:** a manual tree tiling window manager. sway reimplements it on
  Wayland.

## Ideas worth taking

- **Documentation quality.** The user guide is the standard we aim for.
  adopt (P2 onward).
- **Binding modes** (for example a "resize" mode where the arrow keys
  resize). adopt (P2, 0.1.1).
- **Marks and jumping to a marked window.** consider.
- **Restart in place, keeping the layout.** consider (P2, 0.1.4 reload).

## Things to avoid

- **Manual splits as the default.**
